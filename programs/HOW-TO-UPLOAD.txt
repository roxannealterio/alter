NOTHING TO UPLOAD
-----------------
These sit in the site's own "programs" folder, the same way the recipe
photos work. Uploading a program card photo in the admin overrides the
file here.

To change one, replace that file on the server with another photo of
the same name.

A NOTE ON SHAPE
---------------
The cards crop to 3:4 upright, and the program name sits over the top
left corner, so keep that corner clear.
